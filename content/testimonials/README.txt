Testimonials
============

Folder ini sengaja kosong. Selama tidak ada file .md di sini, section Testimonials
tidak dirender sama sekali (di situs maupun di README hasil generate).

Menambah satu testimoni = tambah satu file di sini, contoh `rina.md`:

    ---
    name: Rina
    title: Engineering Manager
    company: Rains
    relation: Atasan langsung
    order: 1
    ---

    Kalimat testimoni di sini.

Field `title` = jabatan pemberi testimoni, `relation` = hubungan (atasan/klien/rekan),
`order` = urutan tampil. Isi body Markdown-nya kutipannya. Jangan pakai tanda kutip di
awal/akhir, situs yang menambahkan.
